# True Hallucinations

Terence McKenna’s **memoir-novel** of the **1971–1972** Amazon period—**literary** companion to the technical claims in *The Invisible Landscape*. Readers often encounter Timewave first here as **narrative** before retracing the **graph mathematics**.
