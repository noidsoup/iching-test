# Zhou yi core oracle text

The **Zhou yi** is the pre-canonical **oracle book**: sixty-four hexagrams with **names**, **hexagram statements**, and **line statements**. It emerged within **Western Zhou** court culture and remained the substrate for all later **Yijing** cosmology.

## How it's used in this project

The Vue app does **not** embed the classical Chinese Zhou yi; it displays **modern English paraphrases** keyed by binary trigram patterns in JSON.

## Key details

- Language: **Early Old Chinese** (composite, stratified).
- Early attestation: **Zuo Zhuan** / **Guoyu** narratives; bronze inscription parallels (scholarly debate).
