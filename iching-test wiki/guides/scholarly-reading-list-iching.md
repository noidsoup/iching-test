# Scholarly reading list — I Ching / Zhou yi

Curated **entry ramp** from web-ingested pointers into standard scholarship. Use external URLs for acquisition; use wiki pages for **concepts** and **entities**.

## Prerequisites

Working familiarity with **pinyin** and basic **Old Chinese** phonology helps for comparing manuscript transcriptions, but many titles below include English apparatus.

## Steps — start here

1. Read [[zhou-yi-vs-yijing-canon]] and [[ten-wings-yi-zhuan]] for strata.
2. Read [[hexagram-orders-and-manuscripts]] before arguing about sequence “logic.”
3. Compare **received** translations with **manuscript-first** editions:
   - Edward Shaughnessy, *I Ching: The Classic of Changes* (Ballantine, 1996) — gateway with philological framing.
   - Richard Rutt, *Zhouyi* / *Book of Changes* (Curzon, 1996) — emphasizes bronze-age context.
4. For **Zhu Xi** practice layer: Joseph Adler’s Zhu Xi commentary translation (Columbia, 2020) — see Wikipedia bibliography list.

## Troubleshooting

- If a blog claims **Fu Xi invented binary computers**, cross-check [[iching-global-reception]] and primary Leibniz scholarship—metaphor ≠ history.
